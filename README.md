# Decoupled LLM User Profiles for Recommendation

This repository contains the code and data required to reproduce the experiments for our project on **decoupled LLM-generated user profiles for recommendation systems**.

The project evaluates profiles generated by **Gemini, LLaMA, and DeepSeek** from two perspectives:

1. **Recommendation Performance** — evaluating how effectively generated profiles retrieve relevant tracks.
2. **Profile Bias / Faithfulness** — evaluating whether generated profiles remain faithful to the user's listening history.

# What the Code Does

## 1. Recommendation Performance

### 1.1 Load Input Data

The notebook loads:

- Training triplets consisting of a profile, positive track, and negative track.
- Test candidates for each `query_key`, including positive and negative tracks.
- Generated profile files for **Gemini, LLaMA, and DeepSeek**.
- Track metadata pools used to construct track representations.

### 1.2 Train the Bi-Encoder

The recommendation model is implemented using **SentenceTransformers**.

- **Base encoder:** `sentence-transformers/all-MiniLM-L6-v2`
- **Training:** 1 epoch
- **Seed:** 42

### 1.3 Evaluate Retrieval Performance

Recommendation quality is evaluated using:

- **Recall@10**
- **NDCG@10**

The notebook produces both per-query evaluation results and an aggregated summary.

### 1.4 Recommendation Outputs

Outputs are written to:

```text
/content/eval_outputs_seed42/
```

The main summary file is:

```text
/content/eval_outputs_seed42/summary_mean_std_seed42.csv
```

---

## 2. Bias and Faithfulness Analysis

The notebook also performs a faithfulness-based analysis of profiles generated by **Gemini, LLaMA, and DeepSeek**.

For each generated profile, we compute:

### Unsupported Claim Rate

The proportion of claims in the generated profile that are not grounded in the user's listening history.

### Genre Coverage

Measures how much of the genre information supported by the user's interactions is preserved in the generated profile.

The main output files are:

```text
/content/biasA_faithfulness_per_profile.csv
/content/biasA_faithfulness_summary.csv
```

# Dataset Files

The file `csv_for_run.zip` contains the following datasets.

### `train_triplets_with_gemini_llama_deepseek_profile_ids.csv`

Training triplets linking each profile generated by the three LLMs to:

- One positive track.
- One sampled negative track.

### `test_candidates_with_gemini_llama_deepseek_profile_ids.csv`

Test candidates for each user-window containing:

- 10 positive tracks.
- A set of negative candidate tracks used for ranking evaluation.

### `generated_profiles_gemini.csv`

User-facing and recommendation-optimized profiles generated by **Gemini** for each user and time window.

### `generated_profiles_llama.csv`

User-facing and recommendation-optimized profiles generated by **LLaMA** for each user and time window.

### `generated_profiles_deepseek.csv`

User-facing and recommendation-optimized profiles generated by **DeepSeek** for each user and time window.

### `50_users_tracks_top15_enriched_.csv`

The top 15 most-listened-to tracks for each user-window, enriched with metadata including:

- Genres
- Country
- Release year

This dataset is used for profile generation and bias analysis.

### `train_pool_1000_set.csv`

Candidate track pool used to sample negative examples during training.

### `test_pool_500_set.csv`

Candidate track pool used as negative candidates during test ranking evaluation.
